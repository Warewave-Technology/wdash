WDASH_ENCRYPTION_KEY is not set

A second factor has to be stored encrypted, and WDash refuses to write a secret as plain text rather than pretend it is protected. Until a key is configured, no local account can finish signing in.

Generate one with:

python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

Set it as WDASH_ENCRYPTION_KEY in the environment and restart. Keep it: everything sealed with it — source passwords, the OIDC client secret, these authenticators — needs the same key to be read back.
